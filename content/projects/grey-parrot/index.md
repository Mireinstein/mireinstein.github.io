Real-time AI bidirectional speech translation integrated as a Chrome extension sidebar in Amazon Connect's CCP interface. Enables live translated transcripts during calls, supporting 12+ languages.

Built with Deepgram Live API for speech-to-text, Google Translate for translation, a FastAPI backend, and AudioWorklet for real-time PCM audio processing. No hardware splitters required — fully browser-based deployment.
