Sustainability-focused web application designed to minimize food waste in college dining halls. Students get real-time menu insights, nutritional analysis, and AI-powered meal recommendations to make informed dining choices.

Built with a React/Next.js frontend, Python backend, and OpenAI API for meal recommendations. Features daily menu insights, plate tracking via image upload, and food waste analytics.
